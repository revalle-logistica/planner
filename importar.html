Como funciona

1. VigênciaInforme a data em que o planner passa a valer. Cada data vira uma versão no histórico.
2. ArquivosImporte cada arquivo no seu botão: visitas, janelas e clientes. A unidade é reconhecida sozinha.
3. ConferênciaVeja o que vem de arquivo e o que é reaproveitado antes de publicar.
4. PublicarA versão vai para o site e fica disponível para todo o time.

1Vigência do planner

Se a data já existir no histórico, a versão é atualizada (só as unidades com arquivo novo mudam). Se for uma data nova, é criada uma nova versão.

2Arquivos

Clique em Importar ou arraste os arquivos para a caixa certa (um arquivo por unidade; pode escolher os 4 de uma vez). Nenhum é obrigatório: o que faltar é reaproveitado, conforme a conferência abaixo.

3Conferência por unidade

Quando não tem arquivo, o painel reaproveita: o pré vem do pós do planner anterior; as coordenadas vêm da última versão que tinha a unidade.
Informe a vigência e solte os arquivos.

4Publicar

A publicação grava a versão no Drive da Logística e ela aparece para todo o time na hora. Só o administrador publica.
